# Experiments & Research Utilities

This directory contains offline experimentation, computer vision scripts, and exploratory image processing routines used during UI/UX prototyping.

## Contents
- **`asset_pipeline/`**: Contains inpainting, edge-blending, boundary stitching, and seam-correction scripts (`clean_section3_*.py`, `coons_patch.py`, `expand_section3_bg.py`) and associated preview outputs used when preparing the oceanographic background visuals.

> **Note:** Production assets used by the Next.js landing pages are served directly from `frontend/public/`.
